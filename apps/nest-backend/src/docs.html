Log Viewer Agent API

The central backend API that aggregates log data from multiple distributed log agents across the LAN/WAN.

Ngrok Warning Bypass

If you are accessing this API over a free Ngrok tunnel, Ngrok will intercept the first browser request with an HTML warning page. This page cannot be bypassed server-side for browser visits. You must click the blue "Visit Site" button once.

However, for your React Dashboard API calls, you must include the following header to bypass the warning and receive JSON:

"ngrok-skip-browser-warning": "true"

Authentication

POST /api/v1/auth/login

Authenticates a user and returns a Sanctum bearer token.

Request Body

{
  "email": "user@lafrontiere.co.zw",
  "password": "secretpassword"
}

Response (200 OK)

{
  "token": "1|abcdef12345...",
  "user": { ... }
}

Machine Management (Requires Bearer Token)

GET /api/v1/machines

Pings all registered agents and returns their online status and aggregated health data.

Response (200 OK)

{
  "grouped": [ ... ],
  "flat": [ ... ],
  "summary": { "total": 1, "online": 1, "offline": 0 }
}

Log Operations (Requires Bearer Token)

GET /api/v1/machines/{machineId}/logs

Retrieves a list of available log files (dates) for a specific machine.

GET /api/v1/machines/{machineId}/logs/{date}

Fetches parsed log entries for a specific date from a specific machine.

Query Parameters

  • search (optional) - Filter entries by text content
  • level (optional) - Filter by log level (e.g. ERROR, WARN)
  • page (default: 1) - Pagination page number
