# UI Components

The UI is built using reusable React components heavily styled with Tailwind CSS.

## Key Components

1. **`Navbar.jsx`**: Global navigation header, user profile, and dark mode toggle.
2. **`MachineCard.jsx`**: Displays individual agent status, OS, IP address, and available log files.
3. **`LogViewer.jsx`**: The core component that fetches log lines from the remote agent and displays them in a terminal-like window.
